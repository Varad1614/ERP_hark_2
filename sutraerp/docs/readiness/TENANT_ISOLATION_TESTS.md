# Tenant isolation tests (Part 1 Stage 3, DEF-X-003 / C-010 / I-006)

Real PostgreSQL 18, API running as the runtime login role (member of `sutra_app`, NOSUPERUSER, no BYPASSRLS). Source: `apps/api/tests/db_p1_s3_tenant.rs` (job "Rust integration" of SutraERP CI), plus `deploy/ci/db-integrity.sql` (Part 1 demo) and the e2e / pilot suites now serving the API as the runtime role.

Each DB test fails on the Stage 2 base (no RLS: id-only SQL returns the foreign row) and passes on `part1/s3-tenant`.
